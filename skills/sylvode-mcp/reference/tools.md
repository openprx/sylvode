# Sylvode tools

Generated by sylvode-skillgen from the tool catalogue; do not edit. 153 tools in 19 categories.

In search mode (the default) the tool list holds only the entry tools and the task tools. Find a tool with `sylvode_search`, call a `read` tool with `sylvode_read` and a `write` tool with `sylvode_write`. The five task tools are called directly. In full mode, an explicit choice of whoever configures the server, every tool is listed by its own name and called directly.

## tasks: Agent tasks

The protocol of tasks assigned to a bot: get, acknowledge, report progress, complete, fail

Call these directly by name; they are not called through `sylvode_read` or `sylvode_write`.

- `sylvode_task_get` (read) — Read a task assigned to the bot with its source, project and status
- `sylvode_task_ack` (write) — Take a task and state a short plan
- `sylvode_task_progress` (write) — Report progress of a task and keep it alive
- `sylvode_task_complete` (write) — Finish a task and let Sylvode post the reply
- `sylvode_task_fail` (write) — End a task as failed with the reason
